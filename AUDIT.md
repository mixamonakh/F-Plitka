# Аудит и миграция F-Plitka

Проверка выполнена 3 октября 2026 года. Область: пять HTML-страниц, JavaScript, Sass, сборка, зависимости, PHP-mailer, изображения, навигация, формы, калькуляторы, SEO-метаданные и работа в браузере. Публикация не выполнялась.

## Что проверено после переноса

- `npm run check`: ESLint, 5 тестов расчётов/URL, production-сборка, автоматический аудит файлов.
- 5 страниц + `404.html`: 207 элементов изображений, 164 декодируемых файла изображений, 182 локальные цели ссылок/ресурсов; ошибок нет. Проверены также ресурсы CSS, якоря, подписи полей и отсутствие PHP/установщиков/архивов в сборке.
- В видимом Chrome через Playwright MCP: все пять страниц на ширинах 320, 390, 768 и 1440 px — без горизонтального переполнения. На десктопе все видимые изображения декодировались, ошибок JavaScript и локальных HTTP 4xx/5xx не обнаружено.
- 53 проверки поведения: автослайдер; фактические CSS animationstart при прокрутке; меню/подменю/Escape/фокус; формы на всех страницах; каждая категория галереи; стрелки просмотра фото; оба калькулятора, купон, нулевая площадь и услуги с одинаковой ценой; слайдер фотоплитки; уменьшение движения. POST-запросы не отправлялись.
- axe-core на всех пяти страницах: 0 обнаруженных нарушений в выбранных наборах WCAG 2 A/AA и 2.1 AA. Это автоматическая проверка, а не заявление о полной сертификации доступности.
- Готовый `dist/` отдельно открыт как статический сайт: все пять страниц ответили HTTP 200, React-гидратация и открытие меню прошли без ошибок; повторно проверены изображения и ширины 390/1440 px.
- Сборка с тестовым `SITE_URL`: проверены canonical/OG для пяти страниц, пять записей sitemap и ссылка на него в robots. Финальная локальная сборка сделана без тестового домена.
- Сравнение исходных абзацев и заголовков с перенесёнными страницами подтвердило сохранность основного текста; удалено сообщение «Спасибо» от неработающей отправки. Политику и бизнес-утверждения не переписывали.

Машинные результаты и скриншоты находятся в локальной папке `reports/` (не включается в Git). Повторяемые статические проверки — `scripts/audit-site.mjs`; проверка поведения через активную вкладку Playwright MCP — `scripts/browser-smoke.js`.

## Отложено по согласованию / перед публикацией

1. Подключение нового обработчика заявок: канал и контракт ещё не выбраны. Формы сохранены, но заявки через сайт сейчас не отправляются.
2. Новый логотип, название и тексты. Существующие контакты, цены, обещания, акция и текст политики сохранены; их актуальность владелец проверит при ребрендинге. В старых материалах встречаются разные домены.
3. Окончательный домен, хостинг, DNS и публикация. Сейчас сайт работает локально; production не изменялся.
4. Смена старого SMTP-пароля, если он ещё действует. Удаление mailer не устраняет пароль из прежних коммитов.
