# F-Plitka

Возрождение сайта услуг по укладке плитки. React 19 + Vite, исходное оформление, фотографии и тексты MSK-STYLE. Все пять прежних адресов сохранены. При сборке React генерирует готовый HTML каждой страницы, который затем становится интерактивным в браузере.

## Локальный запуск

Node.js 24 LTS (версия указана в `.nvmrc`).

```sh
npm ci
npm run dev
```

Сайт: <http://127.0.0.1:5173/>. Редактировать нужно файлы в `src/`, а не результат сборки в `dist/`.

```sh
npm run check       # ESLint, тесты, сборка, аудит локальных ссылок и изображений
npm run build       # готовый статический сайт в dist/
npm run preview     # просмотр сборки на http://127.0.0.1:4173/
npm audit           # проверка зависимостей
```

`npm run audit:site` проверяет уже собранный `dist/`: ссылки и якоря, дубли ID, подписи полей, вложенные интерактивные элементы, изображения в HTML/CSS и декодирование файлов. Результат — `reports/site-audit.json`. Внешние сервисы в эту команду не входят; результаты их проверки указаны в [AUDIT.md](AUDIT.md).

Для проверки поведения через Playwright MCP: открыть локальный сайт, затем выполнить `browser_run_code_unsafe` с `filename`, указывающим на `scripts/browser-smoke.js`. Проверка использует адрес текущей вкладки, проходит все страницы, меню, галереи, формы, калькуляторы и анимации. Реальные заявки не отправляются. Браузерный профиль из AGENTS.md — основной; отдельный `/Users/misha/.codex/browser-profiles/F-Plitka` использован с разрешения владельца.

## Структура

- `src/App.jsx` — общая структура страниц и модальная заявка.
- `src/components/` — React-компоненты меню, слайдера, форм, галерей, каталога и калькулятора.
- `src/content/*.jsx` — сохранённые тексты и секции исходного сайта, общие блоки используются повторно.
- `src/content/pages.js` — метаданные, навигация, списки услуг, цены калькуляторов и галереи.
- `src/content/site.js` — логотип, название в шапке, телефон и WhatsApp общих компонентов. Название в исходных текстах и метаданных пока сохранено отдельно.
- `src/lib/` — расчёт стоимости, соответствие URL страницам, управление анимациями.
- `src/sass/` — исходные БЭМ-стили, переведённые на Sass `@use`.
- `src/styles.css` — адаптивность, доступность и оформление новых интерактивных компонентов.
- `public/` — локальные изображения и иконки. Шрифты и Animate.css собираются из npm; CDN для них не нужен.
- `scripts/prerender.mjs` — генерация HTML, метаданных и файлов для поисковых систем.
- `tests/` — проверки расчётов и сохранённых URL.

`dist/`, `reports/` и промежуточная `.prerender/` не хранятся в Git. Старые исходники доступны в истории репозитория.

## Формы

По решению владельца формы сохранены, подключение нового обработчика отложено. Кнопка отправки отключена, рядом есть понятное сообщение и ссылки на телефон / WhatsApp. Данные остаются в форме; HTTP-запросов для заявок и сообщения об успешной отправке нет. Новый API, сервис доставки и новые поля не добавлялись.

При подключении обработчика нужно отдельно согласовать канал и контракт. PHP/PHPMailer и SMTP-настройки удалены из рабочих файлов и сборки. **Старый SMTP-пароль присутствовал в Git: если он ещё действующий, его нужно сменить у почтового провайдера.** Удаление файлов не удаляет пароль из истории.

## Публикация

Перед production-сборкой указать окончательный домен в `.env.production` либо в окружении:

```sh
SITE_URL=https://your-domain.ru npm run build
```

При заданном `SITE_URL` создаются canonical, `og:url`, абсолютный `og:image`, `sitemap.xml` и ссылка на sitemap в `robots.txt`. Без домена не подставляется ни старый, ни выдуманный домен; canonical и sitemap пропускаются.

Размещать нужно **только содержимое `dist/`** на статическом хостинге. Сервер должен отдавать существующие `.html` и файлы напрямую; отсутствующие URL — с HTTP 404, при желании с подготовленным `404.html`. Перенаправление всех запросов на `index.html` не требуется. PHP и Node.js на сервере не нужны.

Текущая работа выполнена локально. Хостинг, DNS, публикация и новый бренд не настраивались. Перед запуском предстоят согласованные ребрендинг, обновление текстов/контактов и подключение заявок. Полный результат проверки — [AUDIT.md](AUDIT.md).
